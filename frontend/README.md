# Frontend de Obrixapy

Este directorio está reservado para el frontend generado con Emergent. Antes de
generar código, leer en este orden:

1. `docs/EMERGENT_FRONTEND.md`
2. `docs/FRONTEND_API_CONTRACT.md`
3. `docs/ARCHITECTURE.md`

El frontend usará Supabase exclusivamente para autenticación. Todos los datos de
negocio se consumirán desde la API FastAPI de Obrixapy.
